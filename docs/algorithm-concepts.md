# 알고리즘 개념 정리 기준

지정 교재 파일 없이 작성한다는 사용자 요청에 따라, 제공된 실습·요약 자료의 범위에 맞는 일반적인 입문 개념을 새로 설명했다. 교재 원문 요약이나 교재와 표현이 일치한다는 주장은 하지 않는다.

6개 주제: 기초·자료구조, 효율성 분석, 재귀, 억지기법·완전 탐색, 그래프 탐색, 축소 정복. 이후 강의계획서의 단원은 범위 안내로 유지한다.

보완 사항:
- Big-O와 최악의 경우는 다른 분류 기준이다.
- 기본연산 모델 및 추가 공간 기준을 명시한다.
- 문자열 첫 일치 매칭의 최선은 비어 있지 않은 패턴에서 Θ(m)이다.
- 선택 정렬 교환 방식의 안정성, 삽입 정렬 > 비교의 안정성을 구별한다.
- BFS 최단 경로는 무가중치/동일 비용 간선의 조건을 명시한다.
- 이진 탐색의 정렬 전제, 위상 정렬의 DAG 전제를 설명한다.
- 시각화는 버튼으로 이동하고 스크롤을 가로채지 않는다.
- 성장률 숫자는 측정 시간이 아닌 함수값이다.
- 작은 그래프는 과제 원본과 구별한 보충 예시이다.
