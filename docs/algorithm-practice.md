# 알고리즘 Python 연습실

2·3·4·6주차 실습 PPT의 함수명, 입력, 요구 동작을 중심으로 자유 실습 1개와 과제 연습 21개를 구성했다. 모든 과제의 실행 결과 캡처나 제출을 대신하는 기능은 아니다.

- 기초: gcd1/gcd2/gcd3, 괄호 검사, Top3, 성적 딕셔너리
- 분석: 순차 탐색, 유일성 검사, 이진수 자리수, 실행시간 비교
- 재귀: 팩토리얼, 하노이탑, 피보나치
- 억지기법: 선택 정렬, 문자열 매칭, 4개 도시 TSP
- 그래프: DFS/BFS (알파벳순 이웃), 위상 정렬
- 축소 정복: 삽입 정렬, 이진 탐색, 거듭제곱

간단한 예시 입력·출력은 원문 실습을 학습하기 위한 형태로 구성했다. 팩토리얼의 0 입력, 순차 탐색의 작은 배열은 보충 입력이다. 원문에 결과가 하나로 정해지지 않는 위상 정렬·TSP 등은 정확한 출력 문자열 판정을 하지 않는다. 큰 실행시간 실험 입력은 실행 제한을 넘을 수 있다. 실제 시간은 측정될 때만 표시하며 사전 생성한 시간값은 없다.

기본 예시 출력 비교는 입력을 변경하거나 디버깅 출력이 추가되면 일치하지 않을 수 있다. 자동 채점이나 전체 정답 판정을 의미하지 않는다. 각 실행은 새 Python 전역 변수 공간을 사용하나 표준 라이브러리 및 Worker의 실행 환경은 재사용된다. Python 코드에서 임의로 import한 모듈·가상 파일은 Worker 재시작 전까지 남을 수 있다.

기술 근거: https://pyodide.org/en/stable/usage/index.html

사용자 요청에 따라 빌드·브라우저 실행·테스트는 수행하지 않았다.
