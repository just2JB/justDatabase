# 학습 문제 개념 검토

2026-10-12 기준으로 객관식·OX 32문제와 릴레이션 선택 실습 6문제의 문항, 정답, 해설, 예시의 조건을 검토했습니다. 프로그램 실행 테스트와 저장·복원 브라우저 테스트는 사용자 요청에 따라 수행하지 않았습니다.

## 수정한 내용

- s1: 인스턴스 정답은 유지했습니다. 정의만 묻던 문항을 특정 시점의 실제 투플 집합을 구별하는 예제로 바꿨습니다. 구조·제약조건을 정의하는 스키마와 저장된 데이터의 상태를 명확히 구별합니다.
- r2: 조건을 우연히 만족하는 속성 집합과 키의 종류를 혼동하지 않도록 질문과 선택지를 다듬었습니다.
- r5: 이론적인 릴레이션의 중복 금지와 실제 SQL 테이블에서의 중복 허용 가능성을 구별했습니다.
- DBS 학습 화면·검색의 인스턴스 설명에도 특정 시점의 데이터 상태라는 의미를 추가했습니다.

## 검토 범위

| 문항 | 검토 기준 |
| --- | --- |
| b1–b8 | 자료의 데이터·정보 정의, 통합·저장·공유·운영, 3V, 데이터 분류, 접근성 |
| m1–m8 | 자료의 파일 시스템 한계, 정의·조작·제어, DBMS 장단점과 모델 |
| s1–s8 | 스키마·인스턴스, 3단계 구조, 물리적·논리적 독립성, 메타데이터와 언어 |
| r1–r8 | 차수·카디널리티, 후보키·대체키, 참조·개체 무결성, 릴레이션 특성 |
| p1–p6 | 예시에 명시한 유일성·복합키·NULL·참조 대상·원자성 조건과 정답 선택 집합 |

실습은 예시에서 선언한 조건을 기준으로 채점합니다. 현재 표에서 값이 우연히 다르다는 사실만으로 후보키를 판정하지 않습니다. 외래키 NULL은 각 문제에서 명시한 허용 조건을 따릅니다.
