# 부속질의·데이터 변경 자료 정리

자료: 데이터베이스_7주차_부질의외-1.pptx, 30슬라이드. 텍스트와 삽입된 SQL·결과 표 이미지를 읽어 정리했다. 테스트·빌드·브라우저 검증은 사용자 요청으로 실행하지 않았다.

## 주제별 반영

- 슬라이드 2~5: 기존 마당서점 데이터, 조인·외부조인 페이지의 질의 3-25~3-27과 연결되는 복습 내용.
- 슬라이드 6~21: 부속질의 페이지. WHERE/SELECT/FROM 위치, 스칼라 비교, IN/NOT IN, EXISTS/NOT EXISTS, 상관 질의. 기존 질의 3-28~3-33 활용, 4-12/13/14/16 결과 예제 추가.
- 슬라이드 22: 연습문제 (5)~(13) 9개에 펼치는 SQL 해설과 예상 결과 추가.
- 슬라이드 23~30: 데이터 삽입·수정·삭제 페이지. 질의 3-44~3-50, 생략 열·NULL·INSERT SELECT, WHERE 범위, 외래키 삭제 제한.

## 개념 보완

- 부속질의가 조인보다 항상 빠르지는 않다. 데이터·인덱스·최적화 계획에 따른다.
- 스칼라 위치는 한 열·최대 한 행이며 0행이면 NULL, 다중 행이면 오류. SELECT 위치 분류와 상관 여부 분류를 구별했다.
- NOT EXISTS는 반환 행이 없는 경우 참이다. NOT IN 내부의 NULL 영향을 설명했다.
- PPT의 amount 표기를 기존 Orders.saleprice로 통일했다.
- 질의 3-48의 동일 테이블 직접 부속질의 UPDATE는 MySQL 제한을 설명하고 자기 조인으로 목적을 구현했다.
- INSERT에서 생략한 열은 무조건 NULL이 아니다. 기본값·NULL 허용·엄격 모드를 설명했다.
- DELETE 전체 삭제는 외래키에 의해 실패하거나 정책에 따라 자식 행에 영향을 줄 수 있다.
- 제공되지 않은 Imported_book 데이터를 임의로 생성하지 않았다.
- 시각화의 결과는 화면 내 계산·독립된 예시이며 실제 DB 실행 결과가 아니다. SELECT/FROM의 두 예제와 새 고객 삽입은 이해용 보충 예제로 표시했다.
